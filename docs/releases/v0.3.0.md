# CrowDM 0.3.0 — torrents and packages preview

- Native .torrent and magnet downloads, with metadata/file selection before
  starting, verified pieces, pause/resume, queues and collision-safe output.
- Windows Open with and MAGNET registration, plus controls to register again
  and open Windows Default apps. Existing defaults remain the user's choice.
- TCP/uTP peers, public DHT, trackers and peer exchange; configurable peer
  limits, incoming port, UPnP and upload limit. Downloads are uncapped by default.
- Link Grabber accepts copied link lists or supported link pages, checks
  availability, avoids duplicates and groups related archive parts into
  editable package folders. The saved inbox survives restarting CrowDM.
- Packages show aggregate progress, speed, file states and pause/resume/folder
  controls. Batch downloads follow the shared queue, limits and schedule.
- Optional quiet clipboard collection, bounded link-check concurrency, inbox
  size and one package notification instead of one notification per part.
- A faint Nightwing icon beside selected browser links expands on hover and
  sends the complete selection to the app's Link Grabber with one click.
  Linked labels are supported; nothing is sent just by selecting text.
- Windows notifications now identify CrowDM and use its own logo across
  installed, portable and local builds, with a test button in General settings.
- A dedicated update screen with version, “What's New,” owner-controlled
  announcements, checksum-verified installer downloads and extension guidance.
  Preview commits/releases do not automatically announce updates to users.
- Public GitHub app-download counts by version, without usage tracking.

Torrents support v1 and hybrid metadata; v2-only magnets are not supported yet.
Pieces may be uploaded while downloading; sharing stops on completion.
There is no completed-torrent seeding/ratio management. Speeds depend on available
peers, your network, port reachability and storage. Minimum nonzero torrent rate
is 16 KiB/s per bandwidth share; lower shared budgets produce a clear error.

Link Grabber resolves direct file links and explicit HTTP download targets on
simple host landing pages.
It does not provide JDownloader's full host-plugin/account/captcha coverage.
Archive parts stay together; automatic extraction, archive passwords and
automatic multipart assembly are not included. No download is started merely
by copying links.

This remains an unsigned Windows preview. Install the newer EXE over the
existing app with transfers paused; history and settings are retained. Reload
unpacked extensions and refresh already-open video tabs after upgrading.
See [the manual](https://github.com/Syst4n/CrowDM/blob/main/docs/INSTALL.md).
