# CrowDM 0.3.1 preview

- App updates is now directly accessible from the main sidebar, with installed version, manual checking and extension guidance.
- Link Grabber retries landing pages that reject range probes, retains original source URLs for retries, and explains blocked (HTTP 403) and removed links accurately.
- Retry unavailable rechecks the saved inbox without pasting again. Open in browser helps inspect host verification and access requirements.
- Refreshed GitHub gallery includes selected-link capture, packages, batch settings, torrents and updates.

File hosts with verification challenges, logins or unsupported resolvers may still need their browser download button. This preview does not bypass host verification. Existing downloads, settings and partial files are retained. The matching extension is version 0.3.1; extension 0.3.0 also remains compatible.

Install the setup EXE or extract the portable ZIP. See the manual for browser extension setup. This is a public testing preview; installed-user update announcements are separate.
