# CrowDM 0.2.1 · Nightwing preview

A Windows download manager with browser capture, segmented transfers,
pause/resume, organized folders and video/audio downloads.

## New in this preview

- Nightwing branding throughout the desktop app, installer and extensions.
- A separate Appearance section: choose Light, Dark or Windows matching,
  then one of ten palettes. Nightwing logos, menus and browser controls follow
  the same colors. Subtle motion includes a preview and a separate control
  for following Windows reduced-motion preferences.
- Fixed stale YouTube playlist and page navigation. Current video identities
  are checked when opening a format menu and sending a download; old menus
  are invalidated after navigation.
- MP4 and MKV video options, plus MP3 audio conversion with automatic Audio
  category/folder selection and available embedded artwork.
- Estimated sizes for available formats, direct files and sampled finite
  HLS playlists. Live/unbounded playlists are rejected, missing fragments
  abort rather than silently repeating, and completed media is verified.
- Local previews for images, video frames and embedded audio artwork.
  Video previews skip black intro frames; old cached previews are refreshed.
- Compact capture dialog and resizable details, per-row file location buttons,
  sorting, dated completion times, startup, HTML exclusions and sleep controls.
- Aligned, themed dropdowns with single-line options and keyboard support.
  The sorting menu shows all nine choices without visible scrollbars.
- Pending downloads update their category destinations when the root folder
  changes. Settings clearly show whether category folders are enabled.

## Download

Use the x64 setup EXE for a normal installation, or extract the portable ZIP.
Chromium and Firefox extension ZIPs, a manual, SHA-256 checksums and the
FFmpeg source archive are attached. See the [installation guide](https://github.com/Syst4n/CrowDM/blob/main/docs/INSTALL.md).

After updating, reload CrowDM on your browser's extension page and refresh
already-open video tabs once. Disable other download managers' browser
extensions/integration to make CrowDM the active handler.

This is an early preview. Installers are unsigned, Firefox uses temporary
add-on loading, and DRM/live media are excluded. Video support varies by
site. There is no automatic update service yet.
